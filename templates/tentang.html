Profil Pembuat

Saya Ari Sanjaya Sembiring, mahasiswa Program Studi Teknik Informatika. Website ini dikembangkan sebagai bagian dari penelitian skripsi mengenai penerapan algoritma Prophet untuk memprediksi produksi komoditas perkebunan di Kabupaten Langkat berbasis data Badan Pusat Statistik (BPS).

Sistem ini dirancang untuk mengolah data historis produksi komoditas perkebunan, melakukan proses prediksi berdasarkan pola data deret waktu, serta menampilkan hasil prediksi dalam bentuk tabel dan grafik agar informasi lebih mudah dipahami oleh pengguna.

Selain menghasilkan prediksi periode mendatang, sistem juga menyediakan proses evaluasi model menggunakan nilai MAE, MAPE, RMSE, dan R² sebagai ukuran kinerja model Prophet.

Manfaat Sistem
Informasi Prediksi Produksi
Menampilkan hasil prediksi produksi komoditas perkebunan untuk beberapa tahun mendatang.
Pemanfaatan Data Historis
Membantu memanfaatkan data historis produksi perkebunan yang tersedia sebagai dasar proses prediksi.
Evaluasi Akurasi Model
Menampilkan MAE, MAPE, RMSE dan R² untuk mengetahui kinerja model Prophet terhadap data historis.
Pendukung Informasi
Memberikan informasi tambahan mengenai kecenderungan produksi sebagai bahan pendukung perencanaan.
